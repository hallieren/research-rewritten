# Five-premise comparison table

**How to use.** Judge one real project, premise by premise; three minutes (illustrative). How many broke matters less than knowing where. For every broken premise, the method at every later step gets converted once by the rightmost column, and one line goes into the project README or plan next to the conclusion. A premise that breaks unrecorded leaves the deliverable looking identical to one where all five hold.

```text
Project: ____________   Date: ____________

| # | Premise | On my project | If broken, what fails first | Compensation, translated into an action on this project |
|---|---|---|---|---|
| 1 | Errors can be found cheaply (data still there, recomputable) | holds / broken | The interrogation at step 5 | Move the interrogation forward to step 3; locked criteria are the only chance. My action: ________ |
| 2 | The evidence is machine-readable | holds / broken | Dispatching mechanical checks | Cleanup cost goes into the verification budget, usually larger than the check itself. My action: ________ |
| 3 | The verifier is the producer (you can rerun) | holds / broken | L2 independent re-derivation | L0 and L1 as written; the four attack surfaces of templates/red-team-dispatch-brief.md as the acceptance checklist; spot-check economics still exploring. My action: ________ |
| 4 | The criteria can be written before the run | holds / broken | Step 3, and the whole chain with it | Lock a proxy criterion; write the gap between proxy and real target as a formal limitation. My action: ________ |
| 5 | There is a next round | holds / broken | The conclusion itself | The downgrade ladder in templates/downgrade-note.md; the three no-next-round floors. My action: ________ |

Premises broken: ____ of 5
Line written next to the conclusion for each broken premise: ____________
Signature: ____________ (must be a human)
```

### Self-check
- [ ] All five "holds"? Look again at 3 and 5; at project start there is always a next round, and on signing day nothing was ever rerun. Rejudge both.
- [ ] Compensation column copied as is? Translate each into a concrete action on this project or it is only a sentence you once read.
- [ ] Premise 4 "holds" with a proxy criterion? A proxy is fine; an unadmitted proxy is not. Mark it proxy and write the gap.
- [ ] Two or more broken and nothing pinned? Pin this table at the front of the plan; every later step needs one extra conversion.
