# Controversy map

**How to use.** Draft the map with briefs/controversy-map.md, then fill this table with every paper you read; rows are claims. The hard step cannot be skipped: every paper listed gets an existence check in an academic search engine, about twenty minutes (illustrative), before the map goes anywhere. Any paper not opened in a search stays `exists: unverified`. Done test, asked verbatim: "Can you predict what evidence would change this map?" Run the four coverage lines before closing out; a single search path has systematic blind spots and no prompt volunteers "I missed a community".

> The order of use is fixed. templates/controversy-map.md → templates/paper-card.md → templates/question-sharpening-card.md.

```text
|---|---|---|---|
| ____________ | ____________ | ____________ | ____________ |
| ____________ | ____________ | ____________ | ____________ |

The 1 to 2 disagreements my question lands in (my ruling, not the model's): ____________
Load-bearing papers (3 to 5, illustrative) with citation alerts set: ____________
Admission rule for new papers (rule): a paper enters the skeleton layer if and only if it could change who wins a row above. The rest flows past.
Weekly scan (a fixed half hour, illustrative): the weekly scan prompt in briefs/controversy-map.md.

Coverage check (all four ticked before close-out):
☐ Keyword multipath: 5 to 8 term sets (illustrative) from different terminology systems, one search round each
☐ Citation graph: one layer forward (who cited) and one layer backward (who was cited) from each load-bearing paper
☐ Reverse test: "if one paper could overturn this map, what would it look like and which community would it sit in", then searched for
☐ Human anchor: the map shown to someone who knows the field, asked "what did I miss"

```

### Self-check
- [ ] A listed paper without `exists: confirmed <tool>`? The map has not left draft. Search each one.
- [ ] A citation typed from memory? Check the title word by word against a first-hand source; one word off is a paper that does not exist.
- [ ] A claim entering a decision that was not checked against the passage in the original? Each hand drops a qualifier. Open the original.
- [ ] No line of the form "if A is right, B is wrong"? You have not found the battlefield yet. Keep searching before you sharpen a question.
- [ ] All four coverage lines ticked from one fluent answer? A complete-sounding answer is not coverage. Run each path.
