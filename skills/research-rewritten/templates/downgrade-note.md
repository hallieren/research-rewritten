# Downgrade note

**How to use.** Pre-write this block into every project template now; downgrades happen on the busiest day, and on that day the wording will not get improvised, it will get skipped. Cut layers whole, never the order (rule): the criteria timestamp survives every cut. Ten minutes (illustrative): check the criteria timestamp and nothing else. Thirty minutes: add the citation sample and the reverse question; number tracing is cut whole, a half-done trace is worse than none. No next round: the three floors below. The filled note travels with the conclusion and is cited with the numbers. "No time to verify" and "no time to finish" are the same sentence.

```text
[VERIFICATION LEVEL NOTE]
This conclusion is delivered at the ______ tier (10-minute / 30-minute / 2-hour / no-next-round).

Checked:
- criteria timestamp: before results | after results | none
- Citation spot check: ___ / ___ passed (channel: ______)
- Number tracing: all / sampled ___ / not done
- Independent-channel reverse question: done, weakest claim is ______ / not done

Not checked (each cut step named as it is; "the rest omitted" is not allowed): ____________
Reason (the real constraint: the exact time / budget / permission ceiling): ____________
Exploratory wording in the conclusion sentence (mandatory when the timestamp is after results or none): ☐ done

No-next-round floors (all three, rule):
1 Numbers under the original criteria reported as is; the interrogation's output beside them, labeled post-hoc. Killed is not deleted; deleting is the fraud.
2 "No next round" written into the limitations, specifically: "the ______ this conclusion depends on has only ___ independent units; a confirmatory retest would need about ___ additional samples; this project did not run it."
3 Claim strength lowered to the tier the evidence carries, not to zero. Upward is an unconditional statement on short evidence; downward is being frightened into silence; both are dereliction.

verification level note: <tier>; checked: <list>; not checked: <list>; reason: <the real constraint>
answers when wrong: NOBODY | <person's name>
Signature: ____________ (must be a human)
```

### Self-check
- [ ] "Not checked" says "the rest omitted"? That equals writing nothing; a downgrade without a record looks like the full set. List the cut steps.
- [ ] A little trimmed from every layer? A gap in every line of defense is no defense. Cut the later layers whole, keep the timestamp.
- [ ] Reason says "this one is not important"? Importance is set by destination. Delay delivery instead of downgrading.
- [ ] Ten-minute tier spent reading it through? Reading shows you the other side's strongest face. Check the criteria timestamp only.
